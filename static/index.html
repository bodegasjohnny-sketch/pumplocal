Pump · Metro ng Pump

Each pump has two running totals: the peso totalizer (Money) and the liter totalizer (Volume). Record both at shift start (opening) and shift end (closing). PumpLocal computes pesos and liters dispensed and compares them with the sales recorded this shift. All math is done in code.
